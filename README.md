# read

Publish a Markdown or HTML file as a typography-first web page.

```bash
python3 publish.py ~/notes/whatever.md
# => https://coldbeanage.github.io/read/whatever/
```

Live site: **https://coldbeanage.github.io/read/**

## How it works

`publish.py` renders the document to final HTML, wraps it in `assets/theme.css`,
regenerates the index from `docs/manifest.json`, commits, and pushes. GitHub Pages
serves `docs/` on `main` with `.nojekyll`, so no build runs server-side and nothing
can fail after the push.

Re-publishing the same slug updates that document in place at the same URL.

## Options

```
--slug NAME     URL path segment (default: filename)
--title "X"     override title (default: first # H1)
--desc "X"      override index blurb (default: first ~180 chars)
--theme         force the theme onto a self-styled HTML file
--raw           publish HTML byte-for-byte, no theme
--no-push       build locally only
```

Optional frontmatter: `title`, `subtitle`, `kicker`, `date`, `description`, `slug`.

## Design

- Self-hosted Literata (body), Inter (UI), JetBrains Mono (code) — latin subsets,
  ~1.4 MB total, committed so readers make no third-party requests
- ~68-character measure, 1.7 leading, vertical rhythm on a single unit
- Light and dark, system-following with a persisted manual toggle
- Sticky TOC with scroll-spy, reading progress, read-time, copy-on-code, print CSS
- Markdown: tables, footnotes, admonitions, task/definition lists, `~~del~~`,
  `==mark==`, Pygments highlighting (xcode / github-dark)

## Files

```
publish.py        the only thing you run
assets/theme.css  all styling; CSS custom properties at the top
assets/fonts.css  generated by fetch_fonts.py
fetch_fonts.py    re-download font subsets
shot.py           CDP screenshotter (needs headless Chrome on :9222)
docs/             published output, served by Pages
```

## Requirements

`python3`, `markdown`, `pygments`, `git`, and a configured `origin` remote.
