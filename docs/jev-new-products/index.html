The design space opened when a calibrated judgment costs ~$0.000003 and arrives in <0.5s. Organized by which unique property each idea exploits: cheap (per-item/per-user economics), fast (inside control loops), calibrated (honest abstention → safe automation), parallel (one state read → hundreds of answers), legal-by-construction (typed output can’t hallucinate structure), self-improving (RLCD-style: logged outcomes → better calibration).

Cluster A — The supervision economy (the biggest near-term one)¶

The agentic-AI buildout ($1.3T of projected IT spend by 2029, IDC) creates a market for machine supervisors. Every generative agent needs something faster and cheaper watching it.

  1. Agent referee middleware. Every tool call an agent makes gets a pre-execution judgment: is this action risky? does it match the user’s intent? is this a prompt-injection artifact? Sells to everyone shipping agents. This is literally TypeSafe’s documented use case — but the product version is a policy store + question library + audit log, not raw API access. Exploits: cheap + parallel + legal-by-construction.

  2. Confidence middleware / “the honesty layer.” A standalone service any enterprise system calls to answer one meta-question: should this be automated, reviewed, or escalated? It doesn’t do the work — it allocates work between machines and humans. The product is the calibration itself: per-domain confidence bands, drift monitoring, calibration audits. Nobody sells the honesty signal as the product yet. Exploits: calibrated + self-improving.

  3. LLM output verification-as-a-service. Every generative output gets scored before shipping: does this answer the question? is it consistent with the retrieved docs? does it violate policy? Turns “LLM-as-judge” (currently an expensive, slow, circular practice) into a cheap deterministic-feeling gate. RAG reranking at scale is the entry point (TypeSafe documents it). Exploits: cheap — you can verify every output, not a sample.

  4. Calibration audit trail for regulators. Every decision logged with its probability distribution → provable “we knew the confidence when we acted” records. In a world heading toward AI liability law, the audit log is the compliance product. Sell to banks, insurers, healthcare. Exploits: calibrated + legal-by-construction.

  5. The “777 judgments” QA appliance. Every’s test — 37 docs × 21 questions in 0.7s — generalizes into a product: point it at a codebase, a contract portfolio, a documentation set, a support-ticket backlog, and get a structured interrogation of the whole corpus. “Ask 200 questions of your entire wiki, get a spreadsheet.” Code-review gates, doc-consistency audits, contract-portfolio risk sweeps. Exploits: parallel — the questionnaire-per-corpus pattern is new.

Cluster B — Consumer: judgment as a personal utility¶

  1. The attention cortex. On-device decision model sits between your notifications and you. Not summarization — judgment: “is this worth interrupting dinner for, given what it knows about your calendar, your projects, this sender, this week?” Your phone stops being a delivery mechanism for other people’s urgency. Apple/Google will build this into the OS; the startup version is an email/message triage layer. Exploits: cheap (runs per-notification forever for free, if on-device) + calibrated (a wrong interruptibility call is recoverable — it errs toward showing you).

  2. Portable taste functions. RLCD-style training on your engagement data produces a personal judgment model — your taste as a portable asset. Apps query your model: “would she find this interesting?” rather than the platform’s engagement model deciding. Flips the recommendation economy: taste belongs to the user, platforms bid to serve it. Also the mechanism behind the previous session’s “self-training taste” game idea — generalized to all media. Exploits: self-improving + cheap.

  3. The pocket adjudicator. Everyday micro-disputes: splitting bills, “is this Airbnb damage claim legit,” marketplace disputes, “whose turn is it.” Two parties submit state, get a typed judgment with confidence. Justice-as-an-app for the disputes too small for any existing system — which is most disputes. Exploits: cheap (disputes worth $20 can be adjudicated for $0.0001) + calibrated (low-confidence → suggest mediation).

  4. “Should I trust this?” layer. A browser/phone service that judges claims, listings, profiles, reviews: is this review fake? is this listing misleading? is this price fair for this item? is this profile real? Not a fact-checker that writes prose — a risk score on everything you look at. Exploits: cheap enough to score every item, which is what trust requires — sampling-based trust fails.

  5. Anti-slop filter. Content authenticity judgment as a network service: score the feed for generated/low-effort/misleading content per your own rubric. As generated content floods everything, the counter-market is judgment about content, sold to consumers directly. Exploits: parallel (score 50 attributes of every post in one pass).

Cluster C — SMB & enterprise: the ops brain in a box¶

  1. Small-business judgment appliance. ~400M SMEs globally can’t afford ops staff. A box (or SaaS) watching orders, inventory, inboxes, reviews, making the routine calls: approve this refund (<$X)? reorder this stock? is this email a real lead or spam? is this review worth responding to? High confidence auto-executes, low confidence lands in a daily digest. The entire “back office” as a $50/month product. Exploits: all six — this is the killer SMB product because it replaces judgment-labor, not software.

  2. Instant dispute adjudication for marketplaces. E-commerce dispute resolution currently costs $10–50 per case in human time — which is why small claims get auto-refunded (fraud leaks) or ignored (trust leaks). At ~$0.0001 per adjudication you can actually adjudicate every case: evidence in → chargeback-or-not with confidence → humans only see the ambiguous band. Enables trust on $5 transactions; makes entirely new marketplace categories viable. Exploits: cheap + calibrated — the math only works with honest abstention.

  3. Living policy engines. Today: a policy PDF → consultants → rules engine → constant exceptions. Instead: feed the policy + each case’s state to a decision model. The policy stays in natural language; judgment applies it. Does this expense comply? does this contract need legal review? is this PR within the change window? Compliance stops being a rules-database maintenance problem. Exploits: legal-by-construction (typed answers to policy questions) + cheap (every case, not audits-by-sample).

  4. The meeting-decision layer. Ambient judge in workplace tools: was a commitment made in that call? does this thread need a decision? has this project gone quiet-but-not-done? Reads everything, surfaces the 3 things needing human judgment today. The inverse of AI-notetakers (which generate text nobody reads): it generates priorities. Exploits: parallel judgment over all comms streams at once.

  5. Hiring funnel judgment (with care). Structured screening — does this application meet stated requirements? — is legally sensitive (employment discrimination law) but enormous. The defensible product: consistency-checking and process fairness (was the rubric applied the same way to every candidate?), i.e., auditing human decisions rather than replacing them. Exploits: calibrated — the confidence band maps onto legal defensibility; the catch is real, regulation caps this one.

Cluster D — Regulated/high-stakes: where hallucination killed AI adoption¶

The combo of typed output + honest abstention opens verticals generative AI structurally can’t enter — because “the model might say anything” and “the model never admits uncertainty” were the disqualifying properties.

  1. Prior-auth triage. US prior authorization costs $35–56B/yr administratively; physicians spend ~13 hrs/week on it; McKinsey estimates 50–75% of manual tasks automatable. A decision model reads the request + policy: clearly-covered / clearly-not / send to nurse. The high-confidence auto-approvals alone collapse most of the cost; the calibration is what makes it legally shippable. ~30–50k dedicated PA FTEs and >100k RN-FTE-equivalents of provider time get partially released back to care. Exploits: calibrated — this product literally cannot exist without honest abstention.

  2. Benefits/eligibility pre-screening. Social services, insurance eligibility, grant programs: citizens answer questions, model judges likely-eligibility and routes to the right program. The access-to-justice angle: billions of people can’t access services they’re entitled to because the judgment of eligibility costs more than the benefit. Near-zero-cost pre-screening changes that math. Exploits: cheap + calibrated.

  3. Court filing / admin triage. Which filings are complete, which cases qualify for fast-track, which deadlines are at risk. Courts worldwide have multi-year backlogs; much of it is clerical judgment. Not replacing judges — unclogging the administrative layer around them. Exploits: legal-by-construction + cheap.

  4. Continuous compliance monitoring. Today compliance is sampled audits (check 1% of transactions quarterly). With cheap judgment: every transaction, communication, claim gets scored against policy continuously. Compliance shifts from forensic sampling to real-time filtering — a structurally different product category, sellable to every regulated industry. Exploits: cheap + parallel.

  5. Parametric micro-insurance. Micro-insurance fails economically because adjudicating a $30 crop-damage or flight-delay claim costs more than the claim. Edge-deployed decision model + sensor/satellite state → instant adjudication → micro-insurance becomes viable for the ~1.4B unbanked/underinsured. The decision cost was the product’s missing piece. Exploits: cheap — the entire business model only closes at ~$0.0001/claim.

  6. Clinical triage kiosks. Pharmacy/village-kiosk symptom judgment: structured intake → self-care / see-a-doctor-this-week / urgent care now with honest confidence. The abstention band is the safety story — it never pretends to be sure. Distribution through pharmacies and NGOs in under-doctored regions. Exploits: calibrated — calibrated abstention is the difference between a triage tool and a liability.

Cluster E — The physical world (requires the on-device future, but it’s coming)¶

  1. Eldercare ambient judgment. Ambient sensors → a decision model that knows this person’s normal: “is tonight’s behavior anomalous-for-her? rising fall risk? call the daughter or call 911?” The calibration property is the whole product — families accept automated monitoring only if it demonstrably knows when it’s unsure. Exploits: calibrated + self-improving (learns each person’s baseline).

  2. Agricultural edge decisions. Per-field/per-animal judgment on cheap offline hardware in bandwidth-poor regions: is this crop stressed? treat or wait? is this animal’s movement normal? Precision agriculture’s insights currently require connectivity + agronomist time; a local judgment model makes it work on a solar panel in a field. Exploits: cheap + fast + (future) on-device.

  3. Grid/DER orchestration. Distributed energy resources need thousands of small decisions per second per region — island this battery? shed this load? accept this solar forecast? Judgment calls that are too unstructured for SCADA rules and too fast for any API. The on-device version of this model class is the missing control layer for decentralized grids. Exploits: fast + legal-by-construction.

  4. Manufacturing QC judgment layer. Beyond pass/fail vision models: “given this defect pattern + this batch’s history + current orders, rework or scrap? is this drift trend worth stopping the line?” The contextual judgment that today requires a floor supervisor. Exploits: parallel (defect type + severity + context questions in one pass) + calibrated (stopping a line wrongly is expensive — honest confidence is mandatory).

  5. Disaster/offline resilience. Decision models on edge hardware that keep working when connectivity dies: field triage, resource allocation, damage assessment from drone feeds, all judged locally during disasters when cloud AI is unreachable. The offline property is the product. Exploits: on-device future + fast.

Cluster F — Media, games, and the weird ones¶

  1. The game GM (from the previous session — it belongs in this list as the canonical case): every frame/event is a semantic judgment call instead of a dice roll; calibration bounds the novelty; engagement-as-reward trains per-player taste. The general pattern — authored atoms + judgment layer + engagement feedback — extends beyond games to interactive fiction, fitness coaching, language tutors, and any adaptive-experience product.

  2. Adaptive mastery engine for education. The decision model never teaches — it judges: has she mastered this? is this error a slip or a misconception? which of the authored exercises next? is she frustrated? Curriculum stays authored by teachers; the model supplies per-student judgment that previously required a 1:1 tutor. Tutoring’s Bloom-2-sigma effect was always a judgment bottleneck, not a content bottleneck. Exploits: parallel + calibrated + self-improving.

  3. Machine-to-machine arbitration. When agent fleets transact (agent of buyer ↔ agent of seller ↔ agent of logistics), disputes and decisions need a neutral, instant, cheap arbiter. A decision model as the arbitration layer of agent commerce — “escrow judgment.” This doesn’t exist yet because agent commerce doesn’t, but it’s a precondition. Exploits: cheap + legal-by-construction — arbitration output must be typed to be executable.

  4. The decision marketplace. Question sets become sellable IP: a domain expert encodes their judgment as a calibrated question library (“how a senior underwriter reads a submission,” “how a good editor reads a pitch”) and licenses it. Expertise unbundles from the expert’s time — the expert sells the questions, the model supplies the judgment at scale. Exploits: parallel + cheap — the library is worthless if each question is expensive.

  5. Governance/autopilot for DAOs, co-ops, HOAs, clubs. Small organizations drown in small decisions nobody wants to make. Typed judgment over proposals: does this meet the charter? quorum-risk? financial-risk score? Democracy’s administrative layer as a service. Weird, real, and possible today. Exploits: cheap + calibrated.

  6. “The second opinion” API. Every product’s consequential user-facing decision gets a cheap automatic second opinion before executing: a different question set judging the same state. Disagreement between the two = escalation trigger. Redundant judgment as a reliability pattern — like dual-channel avionics for software decisions. Exploits: cheap enough that paying twice for judgment is trivial.

The meta-pattern¶

Notice what all of these share: the product is not the model — it’s the question set, the confidence bands, and the escalation path. The model commoditizes judgment; the defensible products are (a) domain question libraries, (b) per-domain calibration validation, (c) the workflow that handles the low-confidence band. Whoever owns “what to ask” and “when to trust” owns the layer.

The single most underexplored idea in this list: #2 and #30 — selling the honesty signal and selling the questions. The obvious businesses (supervise agents, triage tickets) will be crowded within a year. The weird ones (portable taste, pocket adjudicator, question-set marketplaces) are where the new categories form.
